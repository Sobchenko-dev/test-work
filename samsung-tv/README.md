# Samsung UE49KU6470 — оптимізація

## Пристрій
| Параметр | Значення |
|---|---|
| Модель | UE49KU6470U (код UE49KU6470UXZG, Version 01) |
| Рік / серія | 2016, KU (UHD, 4K) |
| ОС | Tizen 2.4 |
| Прошивка | 1270 (на момент старту) |
| Мережа | Wi‑Fi, домашній роутер |

## Обмеження платформи (чесно)
- Передвстановлені системні застосунки Samsung **не видаляються** без root, а робочого root для Tizen 2.4 (серія K) публічно немає. Видалити можна лише те, що ставилося з магазину.
- RAM мала (~1.5 ГБ), фонові процеси Smart Hub частково вимикаються лише через налаштування.
- Сторонні застосунки — тільки через **Developer Mode + Tizen Studio** з ПК у тій самій мережі. Багато сучасних проєктів (TizenBrew/TizenTube, Jellyfin for Tizen) вимагають новішого Tizen — сумісність з 2.4 перевіряємо окремо для кожного.

## Етап 1 — без ПК (на самому ТВ)
1. **Прошивка:** Налаштування → Підтримка → Оновлення ПЗ → «Оновити зараз». Після — вимкнути «Автооновлення» (щоб не прилетіло щось, що зламає sideload).
2. **Видалити зайве:** Apps → застосунок → Параметри → Видалити (все, що не використовується).
3. **Вимкнути автозапуск:** Налаштування → Smart Hub → «Автозапуск Smart Hub» = Вимк, «Автозапуск останньої програми» = Вимк.
4. **Приватність / фонові служби:** Налаштування → Підтримка → Умови та політика → вимкнути «Інформаційні служби перегляду», «Реклама на основі інтересів», «Служби розпізнавання голосу» (якщо голос не потрібен).
5. **Samsung Instant On:** Система → Експертні налаштування → вимкнути, якщо ТВ «тупить» після довгої роботи (старт буде повільніший, але RAM чистіша).
6. **Скидання Smart Hub:** Підтримка → Самодіагностика → «Скинути Smart Hub» (PIN 0000) — чистить кеш і накопичене сміття. Після цього заново ставимо тільки потрібне.
7. **Холодний перезапуск:** утримувати кнопку живлення пульта до появи логотипу — звільняє RAM повністю.

## Етап 2 — корисні фічі
- **Smart View / DLNA:** медіасервер на ПК/NAS (Jellyfin, Plex, Kodi UPnP) видно прямо в «Джерелах» — без жодних застосунків.
- **Game Mode** (Система → Загальні) для консолі/ПК — менша затримка.
- **Зображення:** режим «Фільм», вимкнути Eco‑датчик освітлення, Auto Motion Plus — за смаком (для фільмів краще Вимк).
- **SmartThings** на телефоні — пульт, вимкнення/ввімкнення, перемикання джерел.

## Етап 3 — сторонні застосунки (потрібен ПК)
1. Apps → на пульті набрати `1 2 3 4 5` → Developer mode = On → вказати IP ПК → перезавантажити ТВ.
2. На ПК: Tizen Studio + Samsung Certificate (TV profile).
3. `sdb connect <IP_ТВ>:26101` → встановлення `.wgt`.
4. Кандидати: _список уточнюється_ (Seena — ?, Media Station X, Jellyfin, ін.).

## Етап 4 — план «Б»
Якщо Tizen 2.4 не тягне потрібні застосунки — найефективніше апгрейд: HDMI‑стік (Google TV Streamer / Chromecast, Fire TV, Mi TV Stick) і повністю обійти Smart Hub.
